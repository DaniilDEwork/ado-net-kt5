КТ-5 - Repository и UnitOfWork

Главная Категории Товары

API каталога товаров

Проект использует Entity Framework Core, SQLite и шаблоны Repository и UnitOfWork

У каждого товара есть категория, название, цена и необязательное описание

  • Запросы к категориям - получение, создание, изменение и удаление
  • Запросы к товарам - получение, создание, изменение и удаление
  • GET /api/categories - JSON со всеми категориями
  • GET /api/products - JSON со всеми товарами
  • Коллекция Postman - готовые запросы и проверки ответов

Работа с запросами

Выберите страницу категорий или товаров, затем операцию и нажмите «Отправить запрос»

Для изменения или удаления записи укажите её ID, для создания и изменения заполните JSON

Сначала создаётся категория, затем товар с её ID, при удалении порядок обратный

При первом запуске добавляются две категории и три товара, изменения сохраняются в базе данных
